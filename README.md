

게임
- 맞출때까지 계속 진행시킴
- 맞춘다면 새로 정답숫자 발급

유저
- 서로다른 1~9까지의 3자리수 입력
- 맞춘다면 종료할지 한번 더 할지 입력

컴퓨터
- 정답 3자리 생성

공
- 스트라이크 볼 낫싱 출력

숫자검증기
- 입력받은 숫자가 옳바른지 판단

명령어검증기
- 입력받은 명령어가 옳바른지 판단


1. 3자리수 생성
    - 중복되지 않은지 검증
2. 3자리수 입력
    - 중복된 수가 없는지 검증
    - 옳바른 수인지 검증
    - 3자리 수인지 검증
3. 공 검증
    - 옳바른 공인지 검증
    - 스트라이크 개수
    - 볼 개수 
    - 낫싱 판단
4. 결과 출력
5. 일치시 종료
6. 다시 시작하거나 종료
